## Image Extraction Features

Which kinds of images the libraries extract, each tested with a small PDF.

|      Feature      | pypdfium2 | pdfminer.six | PyMuPDF | pypdf |
| :---------------- | :-------: | :----------: | :-----: | :---: |
| RGB, Flate        |     ✓     |      ✓       |    ✓    |   ✓   |
| JPEG              |     ✓     |      ✓       |    ✓    |   ✓   |
| JPEG 2000         |     ✓     |      ✓       |    ✓    |   ✓   |
| Grayscale         |     ✓     |      ✓       |    ✓    |   ✓   |
| CMYK              |     ✓     |      ✓       |    ✓    |   ✓   |
| Indexed           |     ✓     |      ◐       |    ✓    |   ✓   |
| 16 bits           |     ◐     |      ✗       |    ✓    |   ◐   |
| 1 bit             |     ✓     |      ✓       |    ✓    |   ✓   |
| CCITT Group 4     |     ✓     |      ✓       |    ✓    |   ✓   |
| LZW               |     ✓     |      ✓       |    ✓    |   ✓   |
| Filter chain      |     ✓     |      ✓       |    ✓    |   ✓   |
| Inline image      |     ✓     |      ✓       |    ✗    |   ✓   |
| In a form XObject |     ✓     |      ✓       |    ✓    |   ✓   |
| Soft mask         |     ✓     |      ✓       |    ✓    |   ✓   |
| Stencil mask      |     ✓     |      ✓       |    ✓    |   ✓   |
| Drawn twice       |     2     |      2       |    1    |   1   |

✓: the image is extracted. ◐: an image is extracted, but it is not the picture or cannot be opened. ✗: no image. ⚠: an error. For *Drawn twice*, the number of extracted images.

<details>
<summary>The features, and what went wrong</summary>

* **RGB, Flate**: 8 bits per component, FlateDecode.
* **JPEG**: DCTDecode.
* **JPEG 2000**: JPXDecode.
* **Grayscale**: DeviceGray.
* **CMYK**: DeviceCMYK.
* **Indexed**: A palette of 16 colors.
  pdfminer.six: `page-1-Im1.bmp: another picture (correlation -0.45)`
* **16 bits**: 16 bits per component.
  pypdfium2: `page-1-image-1.jpg: another picture (correlation -0.04)`; pdfminer.six: `no image`; pypdf: `Im1.png: another picture (correlation -0.04)`
* **1 bit**: Black and white, 1 bit per pixel.
* **CCITT Group 4**: CCITTFaxDecode, as in scanned documents.
* **LZW**: LZWDecode.
* **Filter chain**: ASCII85Decode and FlateDecode.
* **Inline image**: An image inside the content stream (BI ... ID ... EI).
  PyMuPDF: `no image`
* **In a form XObject**: An image drawn by a form XObject.
* **Soft mask**: An image with an /SMask (transparency).
* **Stencil mask**: An /ImageMask, painted with the fill color.
* **Drawn twice**: The same image XObject drawn twice: the number of extracted images.

</details>
